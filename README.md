# Взаимодействие двух стационарных сверхзвуковых потоков реального газа

Программная часть ВКР: точное решение задачи о распаде произвольного разрыва для
двух сверхзвуковых потоков совершенного газа с переменной теплоёмкостью `cp(T)`.

## Что делает

По параметрам двух набегающих потоков (давление, температура, число Маха, угол)
программа определяет конфигурацию взаимодействия и рассчитывает все параметры газа
в зоне взаимодействия. Задача сводится к нелинейному уравнению относительно
давления `p*`, которое решается сканированием с уточнением бисекцией; внутри
волновых функций используются метод Ньютона (скачок) и формула Симпсона (веер).

Конфигурация определяется автоматически:
- **скачок–скачок** — сжатие с обеих сторон;
- **разрежение–разрежение** — расширение с обеих сторон;
- **смешанная** — скачок + волна разрежения;
- **режим Маха** — регулярного решения нет.

Поддерживаются две модели газа:
- идеальный газ (`γ = const`);
- реальный воздух с переменной теплоёмкостью `cp(T)` по полиномам NASA.

## Структура

```
src/
  gas.hpp          термодинамика (идеальный газ / NASA-полиномы)
  riemann.hpp      решатель задачи о распаде разрыва (ядро)
  profile.hpp      построение автомодельного профиля по углу φ
  experiments.hpp  серии численных экспериментов
  io.hpp           запись CSV
  main.cpp         головной модуль
input/
  params.hpp       входные параметры и настройки решателя
plots/
  plot_prof.py        автомодельные профили конфигураций
  plot_anal.py        карта областей существования и зависимости углов
  plot_geometry.py    коническая картина течения (веер лучей)
  plot_streamlines.py линии тока
```

## Сборка и запуск

Требуется компилятор C++17 (например, g++) и Python 3 с `numpy` и `matplotlib`.

```bash
# 1. сборка и расчёт (результаты -> results/*.csv)
g++ -std=c++17 -O3 -o main.exe src/main.cpp
./main.exe

# 2. построение графиков (-> plots/*.png)
cd plots
python plot_prof.py
python plot_anal.py
python plot_geometry.py
python plot_streamlines.py
```

## Свои конфигурации

Все входные данные и численные настройки задаются в `input/params.hpp`.
Собственные постановки добавляются строками в таблицу `CUSTOM_CASES`
(левый и правый потоки задаются независимо), после чего нужно пересобрать и
запустить программу.
